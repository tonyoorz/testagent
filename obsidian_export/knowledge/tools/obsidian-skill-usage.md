# Obsidian Skill Usage

## Summary
Personal skill for creating structured Obsidian notes with vault-first, mirror-second workflow.

## Note Types
- `knowledge`: Architecture notes, concepts, learnings
- `worklog`: Daily logs, meetings, progress
- `export`: Repository-to-vault exports, conversation exports

## Trigger Phrases
- Chinese: 整理成 Obsidian 笔记, 写日报, 会议纪要
- English: create knowledge note, write worklog, export to vault

## Key Rules
1. Vault-first, mirror-second
2. Append by default (no overwrite)
3. Conversation export is summary-only
