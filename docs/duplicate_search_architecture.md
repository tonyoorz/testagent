## 3. 数据标注流程（无需人工标注！）

```
传统方式 (你的系统不需要):
  人工标注员 → 看每条数据 → 标记正/负 → 成本高、慢

你的方式 (自动挖掘):
  用户正常使用 → 系统自动记录 → TrainingDataMiner 自动生成标注

  标注来源：
  ┌─────────────────────────────────────────────────┐
  │  显式反馈 (用户主动点的)         权重=1.0  质量:高│
  │  • ✅ "是重复" → 正例                           │
  │  • ❌ "不是"   → 负例                           │
  │  • 🤔 "不确定" → 不用                            │
  ├─────────────────────────────────────────────────┤
  │  隐式反馈 (从行为推断)           权重=0.3-0.6 质量:中│
  │  • 用户点击了某个 ticket → 大概是正例 (0.6)     │
  │  • 排第1但用户没理它  → 大概是负例 (0.3)        │
  │  • 整页结果都没操作   → 全是负例 (0.4)          │
  ├─────────────────────────────────────────────────┤
  │  全页拒绝                       权重=0.4  质量:低│
  │  • 搜索了但什么都没点 → 所有结果都是负例        │
  └─────────────────────────────────────────────────┘
```

## 4. 模型选择优先级

```
用户搜索 → 向量相似度初始排序
                │
                ▼
         ┌──────────────┐
         │ 有 Fine-tuned │──是──► 用新模型重算 embedding 相似度
         │   模型？      │        + ClickBoost 微调 (75/25)
         └──────┬───────┘
                │否
                ▼
         ┌──────────────┐
         │ LR ReRanker  │──是──► ClickBoost + LR 特征重排 (60/40)
         │   就绪？      │
         └──────┬───────┘
                │否
                ▼
         ┌──────────────┐
         │  纯 ClickBoost │──► 统计微调 ±0.075
         │  (总是可用)    │
         └──────────────┘
```
