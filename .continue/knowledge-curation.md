# Continue Configuration for Knowledge Curation

## Custom Commands

### /note - 整理知识笔记

当用户输入 `/note` 时：

1. 首先确认："你想整理什么知识点？"

2. 进行价值测试：
   - 6个月后你还需要这个吗？
   - 这个洞察对你来说是独特的吗？
   - 你真正理解了吗？

3. 如果通过，继续澄清：
   - 核心收获是什么？
   - 如何应用？

4. 生成笔记草稿让用户审阅

5. 用户批准后保存到 Obsidian vault
